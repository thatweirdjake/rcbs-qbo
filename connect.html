Connect / reconnect QuickBooks

The connection is started from the RCBS workstation where the dashboard runs:

  1. Open a terminal in the Dashboard folder.
  2. Run python rcbs_quickbooks.py --autorizar.
  3. Sign in to QuickBooks in the browser window that opens and approve access.

Run the same command again to reconnect if access expires or was revoked.
